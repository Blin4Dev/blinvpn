# BlinVPN 3.0

Telegram-бот, мини-приложение, панель управления и бэкенд VPN-сервиса на Remnawave.

С версии 3.0 сервис работает на **двух серверах**:

| Сервер | Что на нём | Кто его видит |
|---|---|---|
| **Панель** | панель управления, бот, Remnawave, база, бэкапы, вебхуки (обработка) | только вы и сотрудники |
| **Edge** | мини-приложение, страница подписки, XBM, приём вебхуков | пользователи, платёжки, Telegram |

Пользователи общаются только с edge. Панель **сама** подключается к edge по WireGuard, поэтому на edge
нет ни IP, ни домена панели, ни её секретов. Если edge взломают, через него не попасть ни в панель, ни в Remnawave.

```
 пользователи ──► edge: nginx ─┬─ мини-апп (статика)
                               ├─ /api/app/*  ─────────┐
                               ├─ подписка: XBM / страница подписки ─┐
                               └─ вебхуки платёжек ────┤             │
                                                       ▼             ▼
                         WireGuard 10.213.0.0/24 (панель звонит сама)
                                                       │
 панель: edge-ingress 10.213.0.1:8443 — единственная дверь из туннеля
         ├─ api-public 127.0.0.1:8001  (только /api/app)
         ├─ webhook    127.0.0.1:5000  (9 платёжек)
         └─ Remnawave  127.0.0.1:3000  (только подписка и конфиг страницы подписки)
         api (панель) 127.0.0.1:8000 ◄─ nginx :443 (домен панели), бот, монитор, база
```

## Что защищает 3.0

- **Адрес панели не уходит пользователям.** Ссылки подписки строятся только из домена подписки (раньше при
  неудаче брался адрес Remnawave). Письма отправляет edge, а не панель. Каждый ответ, который идёт из
  туннеля, проверяется: если в нём IP или домен панели, ответ не отдаётся, а в форум приходит тревога.
  Тексты для пользователей (рассылки, ответы поддержки, оферта) с адресом панели не сохраняются.
- **Дверь в панель одна** (`edge-ingress`): белый список путей и методов, чистка заголовков, лимиты.
  Токен Remnawave для страницы подписки ingress подставляет сам, на edge его нет.
- **Процесс мини-аппа отделён от панели.** В `api-public` нет ни одной ручки панели, и фоновых задач он не запускает.
- **Реальный IP клиента** берётся только от своего прокси: `CF-Connecting-IP` и `X-Forwarded-For` больше нельзя
  подделать, чтобы обойти лимиты входа в панель.
- Панель на запросы по IP рвёт TLS, не индексируется поисковиками, отдаёт `Referrer-Policy: no-referrer` и CSP.
- Исправлены двойные чеки «Мой налог» (захват строки в БД вместо внутрипроцессной блокировки),
  проверка IP вебхуков ЮKassa/Platega, URL вебхуков без запасного домена мини-аппа, лимит обновления ключа WATA.

## Установка

Нужны два сервера (Ubuntu 22.04+/Debian 12+), желательно в разных подсетях.

**Домены.** Все пять доменов должны быть разными, а домен панели лучше взять отдельный и не похожий на бренд:

| Домен | A-запись | Пример |
|---|---|---|
| панель BlinVPN | сервер панели | `cp.some-neutral.net` |
| UI Remnawave (по желанию) | сервер панели | `rw.some-neutral.net` |
| мини-приложение | edge | `app.blinvpn.com` |
| подписка | edge | `sub.blinvpn.com` |
| вебхуки платёжек | edge | `pay.other-domain.xyz` |

**1. Сервер панели.** Сначала установите Remnawave: панель на `127.0.0.1:3000`, **без** subscription-page
и без своего nginx/caddy на 80/443. Затем:

```bash
curl -fsSL https://raw.githubusercontent.com/Blin4Dev/blinvpn/main/install.sh -o install.sh
sudo bash install.sh        # → 1) Панель
```

Установщик спросит домены, токен бота и токен Remnawave, предложит перенести данные со старого сервера
(архив `data` + старый `.env`: без старого `.env` не расшифруются ключи платёжек, капчи, почты и S3),
сам исправит `SUB_PUBLIC_DOMAIN` в Remnawave, выпустит сертификаты, поднимет туннель и в конце покажет
**код сопряжения** `BLINPAIR1…`.

**2. Edge-сервер.**

```bash
curl -fsSL https://raw.githubusercontent.com/Blin4Dev/blinvpn/main/install.sh -o install.sh
sudo bash install.sh        # → 2) Edge, вставить код BLINPAIR1…
```

Edge выпустит сертификаты, соберёт мини-приложение, XBM и страницу подписки и покажет **ответный код**
`BLINEDGE1…`. Вставьте его в установщик панели: туннель поднимется, всё проверится само.

**3. После установки:**
- в @BotFather укажите Web App URL и `/setdomain` = домен мини-приложения;
- впишите адреса вебхуков в кабинеты платёжек (установщик их напечатает, они же есть в панели:
  Настройки → Серверы). Lava, Heleket и 2328 передают адрес в каждом счёте сами;
- если используете XBM: Remnawave → Subscription → Response Rules (кнопка «Скопировать правила» в «Балансировщике»);
- почта на своём домене: SPF теперь указывает на **IP edge** (панель покажет его в Настройки → Почта).

## Блокировки и переезды

| Что случилось | Что делать (на сервере панели) |
|---|---|
| заблокировали домен мини-аппа / подписки / вебхуков | купить новый, A-запись → IP edge, `sudo blinvpn domains` (сертификаты и nginx на edge обновятся сами) |
| edge сменил IP | обновить A-записи доменов edge, `sudo blinvpn edge-endpoint НОВЫЙ_IP` |
| edge переезжает на новый сервер | `sudo blinvpn pair` (старый edge сразу теряет доступ), на новом: `sudo bash install.sh` → «Edge» |
| панель сменила IP | только A-запись домена панели: панель сама подключается к edge |
| заблокировали домен панели | новый домен → `sudo blinvpn domains` |

Если edge недоступен, панель, бот и VPN-подключения работают дальше, а в форум приходит тревога.
Если недоступна панель, мини-приложение показывает «техработы», а XBM отдаёт подписку из кэша.

## Команды

Сервер панели:
```
sudo blinvpn status | domains | edge-endpoint <IP> | pair | update | restart | logs [сервис]
```
Edge:
```
sudo blinvpn-edge status | certs | update | logs [сервис] | agent-logs
```
`sudo blinvpn update` обновляет панель и затем, по команде через туннель, edge.

## Правила

- Домены мини-аппа, подписки и вебхуков указывают **только** на edge.
- Не заходите по SSH с панели на edge и обратно: адрес останется в логах. Заходите только со своего компьютера.
- Не добавляйте сервер панели хостом или нодой в Remnawave.
- Скриншоты панели в чат поддержки: проверьте, что не видно адресную строку.
