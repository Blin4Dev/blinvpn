# Установка BlinVPN 3.0 — пошагово

Инструкция для переезда со старого сервера на два новых: **панель** и **edge**.
Читайте сверху вниз и делайте по порядку. Займёт примерно час, большая часть — ожидание.

Команды, которые нужно ввести, выделены вот так:

```bash
команда
```

Всё, что выглядит как `ВОТ_ТАК`, — замените на своё.

---

## 0. Как это устроено (одна минута)

| | Сервер **панели** | Сервер **edge** |
|---|---|---|
| Что на нём | бот, панель BlinVPN, Remnawave, база | мини-приложение, страница подписки, XBM, приём вебхуков |
| Кто его видит | только вы и сотрудники | пользователи, платёжки, Telegram |
| Домены | панели (+ Remnawave по желанию) | мини-аппа, подписки, вебхуков |

Панель **сама** подключается к edge по защищённому туннелю. Edge не знает ни IP, ни домена панели.
Поэтому главное правило: **домены, которые видят пользователи, ведут только на edge**.

## 1. Что подготовить заранее

### 1.1. Заполните себе эту табличку

| Что | Ваше значение |
|---|---|
| IP сервера панели | `IP_ПАНЕЛИ` |
| IP edge-сервера | `IP_EDGE` |
| Домен панели (отдельный, не похожий на бренд, например `cp.some-neutral.net`) | |
| Домен Remnawave (по желанию, тоже нейтральный, например `rw.some-neutral.net`) | |
| Домен мини-приложения (например `app.blinvpn.com`) | |
| Домен подписки (например `sub.blinvpn.com`) | |
| Домен вебхуков (лучше совсем другой домен, например `pay.other-domain.xyz`) | |
| Email для сертификатов | |
| Токен бота (из @BotFather) | |
| Ваш Telegram ID (узнать: @userinfobot) | |
| Username бота без @ | |

> Все пять доменов должны быть **разными**. Домены мини-аппа, подписки и вебхуков **не должны** быть
> поддоменами домена панели и наоборот — установщик это проверит и не даст продолжить.

### 1.2. DNS-записи

В панели вашего DNS-провайдера создайте **A-записи**:

| Домен | Куда указывает |
|---|---|
| домен панели | `IP_ПАНЕЛИ` |
| домен Remnawave (если есть) | `IP_ПАНЕЛИ` |
| домен мини-приложения | `IP_EDGE` |
| домен подписки | `IP_EDGE` |
| домен вебхуков | `IP_EDGE` |

Если DNS у вас в Cloudflare — **выключите оранжевое облако** (режим «DNS only», серое облако) для всех
этих доменов. Иначе не выпустятся сертификаты, а лимиты будут видеть IP Cloudflare вместо пользователей.

Записи обновляются от пары минут до часа. Проверить можно на своём компьютере:

```bash
nslookup ДОМЕН_МИНИАППА
```

Должен показать `IP_EDGE`.

### 1.3. Код на GitHub

Установщик скачивает проект из репозитория `https://github.com/Blin4Dev/blinvpn` (ветка `main`).
Сначала залейте туда содержимое `blinvpn.zip` (версия 3.0.0).

- Репозиторий **публичный** — больше ничего не нужно.
- Репозиторий **другой** — перед установкой на **обоих** серверах выполните
  `export BLINVPN_REPO_URL=https://github.com/ВЛАДЕЛЕЦ/РЕПО.git`
- Репозиторий **приватный** — создайте на GitHub fine-grained токен **только на чтение и только для этого
  репозитория** и укажите `export BLINVPN_REPO_URL=https://ТОКЕН@github.com/ВЛАДЕЛЕЦ/РЕПО.git`.

### 1.4. Порты у хостинга

Если у хостинга есть свой файрвол в личном кабинете (не на сервере), откройте:

- **панель:** TCP 22, 80, 443;
- **edge:** TCP 22, 80, 443 и **UDP 20000–60000** (туннель; точный порт edge-установщик покажет сам, потом
  диапазон можно сузить до него).

Файрвол на самих серверах (UFW) установщик настроит сам.

## 2. Старый сервер: забрать данные

> Пропустите этот раздел, если ставите с нуля.

Зайдите по SSH на **старый** сервер. Старая установка обычно лежит в `/root/blinvpn`.

**2.1. Остановите старый бот.** Если оставить его работать, два бота с одним токеном будут мешать друг
другу, а платежи могут обработаться дважды.

```bash
cd /root/blinvpn
docker compose down
```

**2.2. Упакуйте данные и настройки** (база, вложения, DKIM и **обязательно** `.env` — без него не
расшифруются ключи платёжек, капчи, почты и S3):

```bash
tar -czf /root/blinvpn-data.tar.gz -C /root/blinvpn data .env
```

**2.3. Скачайте архив к себе на компьютер** (команда на **вашем компьютере**):

```bash
scp root@IP_СТАРОГО_СЕРВЕРА:/root/blinvpn-data.tar.gz .
```

**2.4. Загрузите его на сервер панели** (тоже с вашего компьютера):

```bash
scp blinvpn-data.tar.gz root@IP_ПАНЕЛИ:/root/
```

> Копируйте через свой компьютер, а не напрямую между серверами — так в логах серверов не остаётся
> адресов друг друга.

Старый сервер пока не удаляйте — пусть полежит, пока не убедитесь, что всё работает.

## 3. Сервер панели: Remnawave

Remnawave должна стоять на сервере панели **до** установки BlinVPN. Если её там ещё нет — поставьте по
официальной инструкции Remnawave (версия 3.4.5) и перенесите базу со старого сервера по их же инструкции.

После установки проверьте **три вещи**:

**3.1. Remnawave слушает только локально.** Откройте `/opt/remnawave/docker-compose.yml` и найдите у
сервиса панели блок `ports`. Должно быть так:

```yaml
ports:
  - '127.0.0.1:3000:3000'
```

Если там просто `'3000:3000'` — исправьте и перезапустите:

```bash
cd /opt/remnawave && docker compose up -d
```

**3.2. Никакого nginx/Caddy от Remnawave на портах 80 и 443.** BlinVPN сам отдаст домены панели и
Remnawave. Если ставили Remnawave вместе с reverse-proxy — остановите его.

**3.3. Страница подписки (subscription-page) на этом сервере не нужна** — теперь она живёт на edge.
Если она стоит, установщик сам предложит её остановить.

**3.4. Создайте API-токен:** в Remnawave → **Settings → API Tokens** → создать. Скопируйте — понадобится
через минуту.

> По желанию: создайте второй токен **только на чтение** (scopes: `subscriptions`, `subscription-pages`,
> `metadata`) — его будет использовать страница подписки. Безопаснее, но не обязательно.

## 4. Сервер панели: установка BlinVPN

Откройте **два окна терминала** на своём компьютере. В первом зайдите на панель, во втором — на edge
(понадобится в шаге 5). Работаем в первом окне.

```bash
ssh root@IP_ПАНЕЛИ
```

**4.1. Запустите установщик:**

```bash
curl -fsSL https://raw.githubusercontent.com/Blin4Dev/blinvpn/main/install.sh -o install.sh
sudo bash install.sh
```

**4.2. Отвечайте на вопросы:**

| Вопрос | Что ответить |
|---|---|
| Какой это сервер? | `1` (Панель) |
| Путь к архиву … data … | `/root/blinvpn-data.tar.gz` (или Enter, если ставите с нуля) |
| Путь к .env старого сервера | просто Enter — он найдётся в архиве сам |
| Домен панели BlinVPN | домен панели |
| Домен UI Remnawave | домен Remnawave или Enter (тогда вход в Remnawave только через SSH-туннель, см. раздел 9) |
| Домен мини-приложения | домен мини-аппа |
| Домен подписки | домен подписки |
| Домен вебхуков платёжек | домен вебхуков |
| Email для Let's Encrypt | ваш email |
| Токен бота | токен от @BotFather |
| Ваш Telegram ID | цифры |
| Username бота | без @ |
| Адрес Remnawave | Enter (по умолчанию `http://127.0.0.1:3000`) |
| API-токен Remnawave | токен из шага 3.4 (при вводе не отображается — это нормально) |
| Токен для страницы подписки | токен только на чтение или Enter |
| Исправить SUB_PUBLIC_DOMAIN в Remnawave? | `Y` |
| Остановить subscription-page здесь? | `Y` |
| Включить UFW? | `Y` |

Дальше установщик сам выпустит сертификаты, настроит nginx, туннель, файрвол и соберёт контейнеры.
Это 5–15 минут.

**4.3. Логин и пароль панели.** Если ставили **с нуля**, установщик один раз покажет логин и пароль —
**сразу сохраните**. Если переносили базу — вход прежний.

**4.4. Код сопряжения.** В конце установщик покажет:

1. команду для edge-сервера;
2. длинный код, начинающийся с `BLINPAIR1…` — **это секрет**, не пересылайте его через мессенджеры;
3. строку `Ответный код edge:` — и будет ждать.

**Не закрывайте это окно.** Переходите ко второму.

## 5. Edge-сервер: установка

Во **втором** окне:

```bash
ssh root@IP_EDGE
```

> Заходите на edge **со своего компьютера**, а не с сервера панели.

**5.1. Запустите установщик:**

```bash
curl -fsSL https://raw.githubusercontent.com/Blin4Dev/blinvpn/main/install.sh -o install.sh
sudo bash install.sh
```

(Если в шаге 1.3 задавали `BLINVPN_REPO_URL` — сначала выполните тот же `export` и здесь.)

**5.2. Отвечайте:**

| Вопрос | Что ответить |
|---|---|
| Какой это сервер? | `2` (Edge) |
| Код сопряжения | вставьте `BLINPAIR1…` из первого окна |
| (если DNS ещё не обновился) Продолжить? | лучше `N`, подождать и запустить заново |
| Включить UFW? | `Y` |

Edge сам выпустит сертификаты, соберёт мини-приложение, XBM и страницу подписки. 5–15 минут.

**5.3. Ответный код.** В конце edge покажет код, начинающийся с `BLINEDGE1…`, и напишет
«Жду подключения панели».

---

## 6. Соединяем серверы

1. Скопируйте `BLINEDGE1…` из **второго** окна (edge).
2. Вставьте его в **первое** окно (панель), где ждёт `Ответный код edge:`, и нажмите Enter.
3. Панель поднимет туннель и проверит связь. Должно появиться:
   - `✔ туннель поднят`
   - `✔ edge подключён`
4. Во втором окне edge напишет `✔ панель подключилась`.

В конце панель покажет итог: адреса, **адреса вебхуков для платёжек** и подсказки.
Скопируйте этот блок себе — он понадобится в следующем шаге.

> **Не получилось?** Самое частое — у хостинга закрыт UDP на edge (шаг 1.4). Откройте порт и на панели
> выполните `sudo blinvpn pair` — процедура повторится.

## 7. После установки — настроить внешние сервисы

### 7.1. @BotFather

- **Bot Settings → Configure Mini App (или Menu Button)** → URL: `https://ДОМЕН_МИНИАППА`
- `/setdomain` → `ДОМЕН_МИНИАППА` (для входа через Telegram на сайте)

### 7.2. Платёжки

Впишите в личных кабинетах адреса вебхуков, которые показал установщик (их же видно в панели:
**Настройки → Серверы**):

| Платёжка | Адрес | Что сделать |
|---|---|---|
| Platega | `https://ДОМЕН_ВЕБХУКОВ/platega` | вписать в кабинет |
| CisPay | `https://ДОМЕН_ВЕБХУКОВ/cispay` | вписать в кабинет |
| ЮKassa | `https://ДОМЕН_ВЕБХУКОВ/yookassa` | вписать в кабинет |
| PayPalych | `https://ДОМЕН_ВЕБХУКОВ/paypalych` | вписать в кабинет |
| RollyPay | `https://ДОМЕН_ВЕБХУКОВ/rollypay` | вписать в кабинет |
| WATA | `https://ДОМЕН_ВЕБХУКОВ/wata` | вписать в кабинет |
| Lava, Heleket, 2328 | — | ничего, адрес передаётся в каждом счёте сам |

Telegram Stars работают как раньше — ничего делать не нужно.

### 7.3. XBM

В панели BlinVPN откройте **Балансировщик → значок шестерёнки** («Установка и подключение XBM») →
**«Скопировать правила»**. Вставьте их в Remnawave → **Subscription → Response Rules** вместо старых и нажмите **Save**.

### 7.4. Почта (blinvpn.com)

Письма теперь отправляет **edge**. В DNS домена `blinvpn.com` обновите SPF-запись: добавьте туда
`IP_EDGE` (готовую строку панель покажет в **Настройки → Почта**, там же галочки, какие записи уже верные). DKIM переносится вместе с данными и
остаётся прежним.

## 8. Проверка: всё ли работает

На сервере панели:

```bash
sudo blinvpn status
```

Должно быть: все контейнеры `Up (healthy)`, `✔ рукопожатие … с назад`, edge доступен.

Дальше руками:

- [ ] Открывается панель `https://ДОМЕН_ПАНЕЛИ`, можно войти.
- [ ] Бот отвечает на `/start`.
- [ ] Мини-приложение открывается из бота, видна подписка.
- [ ] В мини-приложении «Подписка → Добавить подписку»: ссылка начинается с `https://ДОМЕН_ПОДПИСКИ/`
      (а **не** с домена панели или Remnawave).
- [ ] Ссылка подписки открывается в браузере и импортируется в VPN-клиент, VPN подключается.
- [ ] Тестовая оплата на минимальную сумму проходит и зачисляется.
- [ ] Письмо с кодом входа на почту приходит (если используете вход по почте).
- [ ] В панели **Настройки → Серверы** — edge «на связи», зелёный.

Если всё отмечено — старый сервер можно выключать.

## 9. Полезное на каждый день

### Команды

На сервере **панели**:

| Команда | Что делает |
|---|---|
| `sudo blinvpn status` | состояние контейнеров, туннеля и edge |
| `sudo blinvpn update` | обновить панель и сразу edge (после того как залили новый код на GitHub) |
| `sudo blinvpn logs` | логи (можно указать сервис: `sudo blinvpn logs bot`) |
| `sudo blinvpn restart` | перезапустить всё на панели |
| `sudo blinvpn domains` | сменить домены |
| `sudo blinvpn edge-endpoint НОВЫЙ_IP` | edge сменил IP |
| `sudo blinvpn pair` | подключить новый edge-сервер |

На **edge**: `sudo blinvpn-edge status | certs | update | logs | agent-logs`.

### Заблокировали домен или IP

| Что случилось | Что делать |
|---|---|
| домен мини-аппа / подписки / вебхуков | купить новый → A-запись на `IP_EDGE` → на панели `sudo blinvpn domains` (сертификаты на edge выпустятся сами). Для вебхуков — обновить адреса в кабинетах платёжек |
| у edge новый IP | обновить A-записи доменов edge → на панели `sudo blinvpn edge-endpoint НОВЫЙ_IP` |
| edge переезжает на новый сервер | на панели `sudo blinvpn pair` → на новом сервере шаги 5–6 (старый edge сразу теряет доступ) |
| у панели новый IP | обновить A-запись домена панели — больше ничего |
| заблокировали домен панели | новый домен → A-запись на панель → `sudo blinvpn domains` |

### Вход в Remnawave без домена

Если домен Remnawave не указывали, с **вашего компьютера**:

```bash
ssh -L 3000:127.0.0.1:3000 root@IP_ПАНЕЛИ
```

и откройте в браузере `http://localhost:3000`.

## 10. Правила, чтобы IP панели не утёк

1. Домены мини-аппа, подписки и вебхуков — **только** на edge.
2. Домен панели не связан с ними (другой домен, не поддомен).
3. Не заходите по SSH с панели на edge и обратно — только со своего компьютера.
4. Не добавляйте сервер панели нодой или хостом в Remnawave.
5. Скидывая скриншоты панели пользователям — проверьте, что не видно адресной строки.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| `Порт 80/443 занят другим сервисом` | остановить nginx/Caddy от Remnawave (шаг 3.2) и запустить установщик снова |
| `… указывает на ЭТОТ сервер` | вы направили домен edge на панель — исправьте A-запись на `IP_EDGE` |
| `сертификаты не выпущены` | DNS ещё не обновился или включено оранжевое облако Cloudflare (шаг 1.2) |
| `Remnawave ответила HTTP 401` | неверный API-токен — создайте новый (шаг 3.4) |
| `Remnawave слушает порт 3000 на всех адресах` | шаг 3.1 |
| `Нет рукопожатия с edge` | открыть UDP у хостинга (шаг 1.4), затем `sudo blinvpn pair` |
| `edge-agent не отвечает` | на edge: `sudo systemctl status blinvpn-agent`, затем `sudo blinvpn pair` |
| Ключи платёжек/капчи/почты «пустые» после переноса | не перенёсся старый `.env` — запустите `sudo bash /opt/blinvpn/scripts/install/panel.sh` и на вопросе про .env укажите путь к нему |
| `Ошибка на строке …` на панели | исправьте причину и запустите `sudo bash /opt/blinvpn/scripts/install/panel.sh` — все ответы подставятся, нажимайте Enter |
| `Ошибка на строке …` на edge | `sudo bash /opt/blinvpn/scripts/install/edge.sh` |
