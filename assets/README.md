# assets/

Единый источник картинок проекта (лежит в корне, рядом с `src/`).

Положите сюда **настоящие** файлы (плейсхолдеры не используются):

| Файл        | Где используется                                             |
|-------------|-------------------------------------------------------------|
| `incy.png`  | Аватар INCY в выборе приложения (мини-апп) и на лендинге     |
| `happ.png`  | Аватар Happ в выборе приложения (мини-апп)                   |
| `logo.png`  | Логотип BlinVPN на главной, в онбординге и на лендинге       |

Рекомендуется квадрат ≥ 128×128 px (PNG с прозрачностью) для аватарок.

## Как это раздаётся

- **Мини-приложение** отдаёт их по `/assets/*` — файлы автоматически
  подхватываются сборкой Vite из этого каталога (см. `src/app/vite.config.ts`,
  плагин `blinvpn-root-assets`) и в dev, и в проде.
- **Лендинг** — `install.sh` копирует этот каталог в `${SITE_ROOT}/assets/`.

Просто заменить файлы и пересобрать/переразвернуть — ничего в коде править не нужно.
