Исходники, которые не попадают в сборку.

- `logo-original-640.png` — исходный логотип 640×640 (125 КБ).
  В `assets/logo.png` лежит облегчённая версия 400×400 (~18 КБ):
  `pngquant --quality=85-98 --speed 1 --strip` после уменьшения до 400 px.
  Если меняете логотип — пожмите его так же, иначе сплэш на медленном интернете будет пустым несколько секунд.
